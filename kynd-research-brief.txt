# KYND (FORMERLY DEEPBOUND) — RESEARCH BRIEF

**Product:** Kynd (K-Y-N-D) | **Core technology:** Deep Binding of LLM Virtual Personas
**Location:** /Users/jeremykamber/core/2_areas/kynd

## 1. Problem

Early-stage founders need test users to validate products. Recruiting humans is slow, expensive, doesn't scale. A researcher with 20 interviews cannot simulate how those 20 people would react to 5 different feature concepts.

## 2. Solution

AI-powered user testing with high-fidelity synthetic personas. From minimal input (text description or interview transcripts), Kynd generates realistic personas with Big Five traits, narrative backstories, values, fears, and decision-making styles. Run against live websites, chat individually, generate variations, produce structured analysis.

## 3. Deep Binding Theory

From Moon, Kang et al. (UC Berkeley, 2024):
- Shallow binding: LLM answers as out-group member believes in-group member would (stereotypical)
- Deep binding: LLM answers as authentic in-group member (nuanced, matching real distribution)
- Narrative backstories achieve up to 87% improvement (Wasserstein Distance) over demographic-only

## 4. Techniques Used

1. Narrative backstories (Moon 2024) — 14-18% better alignment
2. Compartmentalized prompts (Wang 2024b) — 4 compartments prevent attention dilution
3. PB&J scaffolds (Joshi 2025) — 6-9% better adherence
4. Persona anchors (SyTTA/Atri 2026) — 40-60% drift reduction
5. ID-RAG (Tan 2025) — factual grounding via retrieval
6. InCharacter eval (Wang 2024a) + PICon (Atri 2026b)

## 5. Architecture: Hexagonal

UI → Actions → Application → Domain (pure TS, zero deps) → Infrastructure (adapters)

10 port interfaces: LlmService, IChatService, ICriticService, IMemoryService, IGazePrediction, VisionAnalysis, BrowserService, DatabaseService, UserRepository, LlmClient.

## 6. Key Features

- Persona Creation: text description → brainstorm → backstory → PB&J → behavioral insights → ID-RAG
- Pricing Analysis: two-phase (scouting URL + parallel persona analysis with concurrency 5)
- Interview-to-Persona Pipeline: extract only observable signals → pool (trigram dedup) → sample → generate → ingest
- Debate Room: multi-persona round-based debate with streaming
- Chat with ID-RAG: compartmentalized prompt + anchors + re-grounding every 4 turns

## 7. Technical Challenges

- Streaming reliability: overhauled to completion-based with Zod validation, 3-min timeout, globalThis stores
- r<0.26 ceiling: bypassed by not extracting personality, only observable signals
- Persona drift: triple anchor injection every turn + periodic re-grounding
- LLM costs: tiered model selection (DeepSeek Flash, Qwen VL, Claude Sonnet 4)
- Browser agent: custom loop over Stagehand act() for persona anchor injection
